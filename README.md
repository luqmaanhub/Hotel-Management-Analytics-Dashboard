# 🏨 Hotel Management Analytics Dashboard

## 📌 Project Overview
This project is an end-to-end Business Intelligence solution built using SQL Server and Power BI. It analyzes hotel information, customer reviews, ratings, room details, and amenities through interactive dashboards.

## 🚀 Technologies Used
- SQL Server
- Power BI
- DAX
- Power Query
- GitHub

## 📊 Dashboard Pages
### 1. Executive Dashboard
- Hotel distribution by state and city
- Hotel category distribution
- Property type distribution
- KPI cards

### 2. Hotel Recommendation Dashboard
- Top-rated hotels
- Guest recommendations
- Review ratings
- Review count analysis

### 3. Hotel Amenities Dashboard
- Wi-Fi availability
- Swimming Pool
- Restaurant
- Gym
- Spa
- Parking
- Doctor on Call
