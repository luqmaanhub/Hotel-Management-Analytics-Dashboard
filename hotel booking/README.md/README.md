# 🏨 Hotel Management Analytics Dashboard

An end-to-end Business Intelligence project developed using **SQL
Server** and **Power BI** to analyze hotel data across India.

## 📌 Project Overview

This project transforms raw hotel data into meaningful business insights
using SQL Server for data preparation and Power BI for visualization.

### Business Questions

-   Which states have the highest number of hotels?
-   Which cities have the highest hotel concentration?
-   Which hotels receive the highest customer ratings?
-   Which hotels have the most customer reviews?
-   Which amenities are offered by hotels?

## 🛠️ Technology Stack

-   SQL Server
-   Power BI Desktop
-   DAX
-   SQL Views
-   GitHub
